# Screenshots for v0.57.0 (Apple design)

Every screen of Team Pulse before (v0.56.0) and after (v0.57.0) the move to Moss 2.0, the Apple based design, taken with `tools/screenshots/shoot.cjs` and the fictional sample team in `tools/screenshots/sample-team.cjs`. All people and notes are fictional.

- `before/` shows v0.56.0, Moss 1.1 with the Ink colors.
- `after/` shows v0.57.0, Moss 2.0.

The file name is the screen name used by the screenshot tool. The screenshots were taken on Linux, so the after set shows that machine's system font. On a Mac the app shows San Francisco. The screenshot tool turns motion off, so the new press, drawer and dialog motion does not show here.
