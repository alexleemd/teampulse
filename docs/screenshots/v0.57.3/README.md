# Screenshots for v0.57.3 (full names first)

The screens that change between v0.57.2 and v0.57.3, taken with `tools/screenshots/shoot.cjs` and the fictional sample team in `tools/screenshots/sample-team.cjs`. All people and notes are fictional.

- `before/` shows v0.57.2. The direct report tiles lead with the four letter code in bold, with the full name on the line below, and Team Tenure on Insights labels its rows by code.
- `after/` shows v0.57.3. The tiles lead with the full name, and the code sits with the level on the line below, as in the table. Team Tenure labels its rows by name, like the Development Path chart above it.

Search, the Data menu, the save conflict dialog and the undo message change only because the tiles show behind them. The other 48 screens are pixel for pixel identical, apart from the version number in the sidebar.
